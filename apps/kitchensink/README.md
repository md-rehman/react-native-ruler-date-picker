# Kitchensink App — react-native-ruler-date-picker

Interactive Expo application showcasing all configurations, themes, graduation presets, and prop combinations for [`react-native-ruler-date-picker`](https://github.com/md-rehman/react-native-ruler-date-picker).

- 📖 **Documentation**: [https://md-rehman.dev/react-native-ruler-date-picker](https://md-rehman.dev/react-native-ruler-date-picker)
- 📱 **Live Expo Snack**: [https://snack.expo.dev/@md-rehman/ruler-date-picker---kitchensink](https://snack.expo.dev/@md-rehman/ruler-date-picker---kitchensink)

## Running Locally

```bash
# Start Expo development server
pnpm --filter kitchensink start

# Run on iOS simulator
pnpm --filter kitchensink ios

# Run on Android emulator
pnpm --filter kitchensink android
```

## Syncing to Expo Snack

Whenever you update the kitchensink demo, sync the changes to Expo Snack:

```bash
pnpm sync-snack
```

> **Direct Account Sync**: Set `EXPO_TOKEN=your_token` in a `.env` file at the root to publish directly under your Expo account. Without a token, the script prints a public snapshot URL that you can open and save in one click.
