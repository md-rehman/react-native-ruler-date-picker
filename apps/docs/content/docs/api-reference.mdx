# API Reference

`react-native-ruler-date-picker` is built on a **3-Tier Layered Architecture**:
1. **Tier 1 (Headless Hooks):** `useRulerDatePicker` & `useRulerDateRangePicker`
2. **Tier 2 (Pre-composed Pickers):** `<RulerDatePicker />` & `<RulerDateRangePicker />`
3. **Tier 3 (Compound Anatomy):** `Ruler.*` & `RulerRange.*`

---

## 1. `<RulerDatePicker />` Props Specification

| Prop | Type | Default | Description |
|---|---|---|---|
| `value` | `Date \| string` | `undefined` | Controlled selected date object or `YYYY-MM-DD` string. |
| `defaultValue` | `Date \| string` | `today` | Initial selected date (uncontrolled). |
| `onChange` | `(date: Date, dateString: string) => void` | `undefined` | Callback fired when scrolling stops or selection changes. |
| `minDate` | `Date \| string` | `-365 days` | Minimum scrollable date boundary. |
| `maxDate` | `Date \| string` | `+365 days` | Maximum scrollable date boundary. |
| `ticks` | `TickRule[] \| 'calendar' \| 'metric' \| 'minimal'` | `'calendar'` | Declarative tick rule array or built-in preset. |
| `tickSpacing` | `number` | `24` | Horizontal gap between tick centers in pixels. |
| `tickThickness` | `number` | `3` | Base width of tick bars in pixels. |
| `theme` | `RulerTheme` | Auto (System) | Color theme object for the component. |
| `indicatorWidth` | `number` | `2` | Width of center needle indicator in pixels. |
| `indicatorHeight` | `number` | `40` | Height of center needle indicator in pixels. |
| `indicatorColor` | `string` | `theme.indicatorColor` | Color of center target indicator bar. |
| `renderIndicator` | `() => ReactNode` | `undefined` | Custom renderer for center indicator needle. |
| `showHeader` | `boolean` | `true` | Whether to display default date & year header. |
| `showResetToToday` | `boolean` | `false` | Renders a "Today" reset button when scrolled away. |
| `renderHeader` | `(date: Date, isToday: boolean, reset: () => void) => ReactNode` | `undefined` | Custom header renderer override. |
| `height` | `number` | `120` | Total height of component container in pixels. |
| `rulerHeight` | `number` | `60` | Height of ruler track area in pixels. |
| `bufferTicks` | `number` | `10` | Off-screen buffer ticks rendered on each side. |
| `debounceMs` | `number` | `100` | Debounce time in ms before invoking `onChange`. |
| `enableHaptics` | `boolean` | `true` | Enable or disable haptic feedback engine. |
| `onHapticTrigger` | `(mode: 'tick' \| 'continuous') => void` | `undefined` | Custom haptic callback to override default `expo-haptics`. |

## 2. Generic Rule-Based Tick System (`TickRule[]`)

Every tick's appearance is defined declaratively. Rules evaluate in order (**first match wins**):

```ts
export interface TickRule {
  /** Condition predicate: 'daily' | 'weekly' | 'monthly' | 'yearly' | { interval: N } | { dayOfWeek: [0, 6] } | ((ctx) => boolean) */
  condition?: TickCondition;
  /** Height of tick bar in pixels */
  height: number;
  /** Width/thickness of tick bar */
  width?: number;
  /** Color of tick bar */
  color?: string;
  /** Label config or boolean */
  label?: boolean | {
    format?: (date: Date) => string;
    color?: string;
    fontSize?: number;
    fontWeight?: 'normal' | '600' | 'bold';
  };
  /** Optional dot badge */
  dot?: boolean | { size?: number; color?: string };
  /** Custom React component render override */
  render?: (ctx: TickContext) => React.ReactNode;
}
```

## 3. `<RulerDateRangePicker />` (Range Selection)

Pre-composed component for date range selection with dual indicators and range highlight span:

```tsx
import { RulerDateRangePicker } from 'react-native-ruler-date-picker';

<RulerDateRangePicker
  value={{ start: new Date(), end: new Date(Date.now() + 7 * 86400000) }}
  onChange={({ startDate, endDate, startString, endString }) => {
    console.log(startString, endString);
  }}
  minSpanDays={1}
  ticks="calendar"
/>
```

## 4. Compound Anatomy API (`Ruler.*` & `RulerRange.*`)

For maximum layout and customization freedom:

```tsx
import { Ruler } from 'react-native-ruler-date-picker';

<Ruler.Root value={selectedDate} onChange={setSelectedDate}>
  <Ruler.Header />
  <Ruler.Track>
    <Ruler.Indicator />
    <Ruler.Ticks />
  </Ruler.Track>
  <Ruler.ResetButton />
</Ruler.Root>
```

## 5. Headless Hooks

Extract physics, Reanimated 3 pan gestures, windowing, and haptics with zero UI:

```tsx
import { useRulerDatePicker, useRulerDateRangePicker } from 'react-native-ruler-date-picker';

const {
  translateX,
  panGesture,
  selectedDate,
  visibleTicks,
  scrollToDate,
  resetToToday,
} = useRulerDatePicker({ value, onChange });
```
